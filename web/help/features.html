Before you begin

Use this page when you know what you want to do. The linked manual sections explain the details. On the iPhone layout, use More for application controls outside the focused Work, Team, and Activity views.

I want to…Go hereWhat happens
Learn the app from the beginningHelp → Run guided setupWalks through project, accounts, routing, and first-task readiness. Setup details.
Follow the shortest first-run instructionsHelp → QuickStartOpens a practice-project walkthrough. QuickStart.
Choose my project without typing a pathProjects, or New task → ProjectLists project folders already found on the server. Projects.
Find a project in a long listProjects → Find a projectFilters existing projects by name or folder. Projects.
Update the project listProjects → Refresh projectsReads the available project folders again. Projects.
Use an existing server folder missing from the listProjects → My project is not listed → Use a folder pathOpens a new task with an explicit Project folder field. Projects.
Check a manually entered folder before runningNew task → Project folder → Inspect folderReads the real project and offers available checks. Projects.
Try the workflow without using my own codeCreate practice projectCreates or reopens the retained label-workshop example. Practice project.
Enter GLM once for both rolesModels → AccountsShares the GLM entry with Architect and Tests & review. Accounts.
Confirm the actual models can answerCheck connectionsSends a small real request to each core role and reports each result. Connection checks.
Use the intended model arrangementModels → Routing → Smart → Save routingApplies the GLM / DeepSeek / MiniMax / GLM role preset. Choosing it makes no model call. Routing.
Keep my own model assignmentsModels → Routing → Manual → Save routingKeeps saved role choices; saving a core role also selects Manual automatically. The app still coordinates the work. Manual routing.
Save entered account keys without a model requestModels → Accounts → Save accountsKeeps entered keys in the running server’s memory. Accounts.
Choose a particular model or serviceModels → AdvancedOpens individual connection settings. Advanced models.
Work without optional OpenRouterModels → Advanced, optional Router disabledCore roles and ordinary deterministic routing remain usable. Optional Router.
Describe a task with a useful starting pointNew task → Starting pointFills a writing template; replace bracketed prompts before starting. Existing edited drafts are kept. Task fields.
Choose checks without knowing their commandNew task → ChecksShows check choices found in the selected project and their source. Checks.
Use my project's exact check commandNew task → Checks → Advanced — use my own check commandAccepts one installed check tool and arguments. Command rules.
Limit how much work the team attemptsNew task → Advanced optionsSets build attempts, model requests, and check timeout. Run limits.
Start workStart taskSaves the request and starts real work using configured providers. New task.
See what the team is doingWorkspace, or phone Work / Team / ActivityShows the current stage and real recorded events. Workspace.
See why the routing layer chose somethingRouting on the workspaceOpens the decision's command, reason, and measured duration. Routing evidence.
Read the Architect's decisionPlan review, Recovery review, or Final reviewOpens the saved decision when available. Workspace panels.
Read actual file findings or test outputView findings or View checksOpens supporting evidence. Evidence.
Pause without throwing away progressPause, then wait for PausedStops advancement at a safe boundary. States.
Continue saved workResume, when offeredUses the same saved starting point and completed stages. Resume.
End this runStop, then wait for StoppedEnds active work and keeps its records. Stop.
Correct the request, checks, or limitsRevise taskOpens a new task with prior settings prefilled; select Start new run after making the changes. Revised tasks.
Read older events without the list movingTurn Follow latest off; use Show earlierKeeps earlier activity available for inspection. Activity.
Reopen yesterday's taskHistoryOpens the saved run and evidence. History.
Download a particular evidence itemView evidence → choose item → DownloadSaves that item's recorded text. Evidence downloads.
Open saved results from the review areaReview desk / Saved checks → Open saved evidenceOpens a saved item without hunting through Activity. Evidence.
Enlarge the permanent evidence deskExpand evidence in UltrawideOpens the evidence in a larger view; closing returns it to the desk. Evidence.
Keep the final proposed changesDownload patch at Ready for reviewSaves the exact preserved changes; original project files remain unchanged. Patch handoff.
Use a light or stronger-contrast interfaceView → ThemeChooses System, Dark, Light, or High contrast. The mascot's waist pack stays safety orange while its background, surrounding lettering, and contrast adapt. Themes.
Use the arrangement for this deviceView → Workspace layoutChooses Automatic, iPhone, iPad, Desktop, Widescreen, or Ultrawide. Layouts.
Search or print a guideHelp page → Find a topic / Print or save as PDFFilters complete guide sections or opens the browser’s print controls. Guide controls.
Recover after an errorRead the next-action message, then the manualGives a correction tied to the actual problem. Recovery.
Recover when the page cannot connectReconnect after restoring accessReads the real server state again. Connection recovery.
