Self-hosted interface assets

Inter Variable, downloaded from the official Inter repository:
https://raw.githubusercontent.com/rsms/inter/master/docs/font-files/InterVariable.woff2
License source: https://raw.githubusercontent.com/rsms/inter/master/LICENSE.txt
The complete font license is in Inter-LICENSE.txt.

The interface uses a small inline set of line icons based on Lucide geometry.
The license from the official Lucide repository is in Lucide-LICENSE.txt:
https://raw.githubusercontent.com/lucide-icons/lucide/main/LICENSE

No font or icon network requests are made when the application runs.
