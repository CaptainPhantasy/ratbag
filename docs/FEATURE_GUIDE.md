## Or: Point me at the button.

**DOCUMENT CLASSIFICATION:** Control map / The short route to useful

**DATE RECORDED:** October 19, 2026

**LOCATION:** Floyd Labs, next to the workbench

**BEVERAGE:** Whatever is still in the coffee pot

Use this page when you know what you want to do. The linked manual sections explain the details. On the iPhone layout, use **More** for application controls outside the focused Work, Team, and Activity views.

| I want to… | Go here | What happens |
| --- | --- | --- |
| Learn the app from the beginning | **Help → Run guided setup** | Walks through project, accounts, routing, and first-task readiness. [Setup details](USER_MANUAL.md#onboarding). |
| Follow the shortest first-run instructions | **Help → QuickStart** | Opens a practice-project walkthrough. [QuickStart](QUICKSTART.md). |
| Choose my project without typing a path | **Projects**, or **New task → Project** | Lists project folders already found on the server. [Projects](USER_MANUAL.md#projects). |
| Find a project in a long list | **Projects → Find a project** | Filters existing projects by name or folder. [Projects](USER_MANUAL.md#projects). |
| Update the project list | **Projects → Refresh projects** | Reads the available project folders again. [Projects](USER_MANUAL.md#projects). |
| Use an existing server folder missing from the list | **Projects → My project is not listed → Use a folder path** | Opens a new task with an explicit Project folder field. [Projects](USER_MANUAL.md#projects). |
| Check a manually entered folder before running | **New task → Project folder → Inspect folder** | Reads the real project and offers available checks. [Projects](USER_MANUAL.md#projects). |
| Try the workflow without using my own code | **Create practice project** | Creates or reopens the retained label-workshop example. [Practice project](USER_MANUAL.md#projects). |
| Enter GLM once for both roles | **Models → Accounts** | Shares the GLM entry with Architect and Tests & review. [Accounts](USER_MANUAL.md#accounts). |
| Confirm the actual models can answer | **Check connections** | Sends a small real request to each core role and reports each result. [Connection checks](USER_MANUAL.md#accounts). |
| Use the intended model arrangement | **Models → Routing → Smart → Save routing** | Applies the GLM / DeepSeek / MiniMax / GLM role preset. Choosing it makes no model call. [Routing](USER_MANUAL.md#routing). |
| Keep my own model assignments | **Models → Routing → Manual → Save routing** | Keeps saved role choices; saving a core role also selects Manual automatically. The app still coordinates the work. [Manual routing](USER_MANUAL.md#routing). |
| Save entered account keys without a model request | **Models → Accounts → Save accounts** | Keeps entered keys in the running server’s memory. [Accounts](USER_MANUAL.md#accounts). |
| Choose a particular model or service | **Models → Advanced** | Opens individual connection settings. [Advanced models](USER_MANUAL.md#advanced-models). |
| Work without optional OpenRouter | **Models → Advanced**, optional Router disabled | Core roles and ordinary deterministic routing remain usable. [Optional Router](USER_MANUAL.md#accounts). |
| Describe a task with a useful starting point | **New task → Starting point** | Fills a writing template; replace bracketed prompts before starting. Existing edited drafts are kept. [Task fields](USER_MANUAL.md#new-task). |
| Choose checks without knowing their command | **New task → Checks** | Shows check choices found in the selected project and their source. [Checks](USER_MANUAL.md#checks). |
| Use my project's exact check command | **New task → Checks → Advanced — use my own check command** | Accepts one installed check tool and arguments. [Command rules](USER_MANUAL.md#checks). |
| Limit how much work the team attempts | **New task → Advanced options** | Sets build attempts, model requests, and check timeout. [Run limits](USER_MANUAL.md#new-task). |
| Start work | **Start task** | Saves the request and starts real work using configured providers. [New task](USER_MANUAL.md#new-task). |
| See what the team is doing | Workspace, or phone **Work / Team / Activity** | Shows the current stage and real recorded events. [Workspace](USER_MANUAL.md#workspace). |
| See why the routing layer chose something | **Routing** on the workspace | Opens the decision's command, reason, and measured duration. [Routing evidence](USER_MANUAL.md#routing). |
| Read the Architect's decision | **Plan review**, **Recovery review**, or **Final review** | Opens the saved decision when available. [Workspace panels](USER_MANUAL.md#workspace). |
| Read actual file findings or test output | **View findings** or **View checks** | Opens supporting evidence. [Evidence](USER_MANUAL.md#evidence). |
| Pause without throwing away progress | **Pause**, then wait for Paused | Stops advancement at a safe boundary. [States](USER_MANUAL.md#states). |
| Continue saved work | **Resume**, when offered | Uses the same saved starting point and completed stages. [Resume](USER_MANUAL.md#states). |
| End this run | **Stop**, then wait for Stopped | Ends active work and keeps its records. [Stop](USER_MANUAL.md#states). |
| Correct the request, checks, or limits | **Revise task** | Opens a new task with prior settings prefilled; select Start new run after making the changes. [Revised tasks](USER_MANUAL.md#history). |
| Read older events without the list moving | Turn **Follow latest** off; use **Show earlier** | Keeps earlier activity available for inspection. [Activity](USER_MANUAL.md#workspace). |
| Reopen yesterday's task | **History** | Opens the saved run and evidence. [History](USER_MANUAL.md#history). |
| Download a particular evidence item | **View evidence → choose item → Download** | Saves that item's recorded text. [Evidence downloads](USER_MANUAL.md#evidence). |
| Open saved results from the review area | **Review desk / Saved checks → Open saved evidence** | Opens a saved item without hunting through Activity. [Evidence](USER_MANUAL.md#evidence). |
| Enlarge the permanent evidence desk | **Expand evidence** in Ultrawide | Opens the evidence in a larger view; closing returns it to the desk. [Evidence](USER_MANUAL.md#evidence). |
| Keep the final proposed changes | **Download patch** at Ready for review | Saves the exact preserved changes; original project files remain unchanged. [Patch handoff](USER_MANUAL.md#evidence). |
| Use a light or stronger-contrast interface | **View → Theme** | Chooses System, Dark, Light, or High contrast. The mascot's waist pack stays safety orange while its background, surrounding lettering, and contrast adapt. [Themes](USER_MANUAL.md#appearance). |
| Use the arrangement for this device | **View → Workspace layout** | Chooses Automatic, iPhone, iPad, Desktop, Widescreen, or Ultrawide. [Layouts](USER_MANUAL.md#appearance). |
| Search or print a guide | **Help page → Find a topic / Print or save as PDF** | Filters complete guide sections or opens the browser’s print controls. [Guide controls](USER_MANUAL.md#using-help). |
| Recover after an error | Read the next-action message, then the manual | Gives a correction tied to the actual problem. [Recovery](USER_MANUAL.md#recovery). |
| Recover when the page cannot connect | **Reconnect** after restoring access | Reads the real server state again. [Connection recovery](USER_MANUAL.md#connection-recovery). |
